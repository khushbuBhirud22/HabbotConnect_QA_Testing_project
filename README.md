# HabotConnect – QA Requirement Analysis & Manual Test Design

 Project Overview:

This project demonstrates my approach to QA analysis for the
Learning Support Assistant Profile Search & Selection Flow.

The project was created using the business requirements and
sample/mock data provided for the QA assignment.

No live web application was provided, so the project focuses on
requirement analysis, test design, boundary analysis, negative
testing, simulated defect identification, and QA documentation.

Objectives:

- Analyze the provided business requirements
- Identify requirement gaps and ambiguities
- Create a manual test strategy
- Design manual test cases
- Apply Equivalence Partitioning
- Apply Boundary Value Analysis
- Perform negative test analysis
- Define binary quality gates
- Document simulated defects

## QA Deliverables

Requirement Analysis:
Identified 3 logical requirement gaps related to:
- Profile eligibility
- Hourly-rate boundaries
- Multiple-filter logic

Manual Test Suite:
Created 5 structured manual test cases covering:
- Default search
- Verification eligibility
- Hourly-rate boundary
- Rate boundary values
- Combined filters

Defect Reports:
Created 2 simulated defect reports covering:
- Unverified profile exposure
- Hourly-rate boundary violation

 Testing Techniques:

- Requirement-based testing
- Equivalence Partitioning
- Boundary Value Analysis
- Negative Testing
- Combination Testing
- Binary Pass/Fail Quality Gates

Test Environment:

No live application was provided.

Therefore, test cases were designed but not executed against a live system.
Actual results were intentionally marked as "Not Executed" rather than
assuming or fabricating execution results.

Important Note
The defects documented in this project are simulated defects based on
the supplied requirements and mock data. They should not be interpreted
as defects reproduced in a live production application.
